# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to **[adityamds05@gmail.com](mailto:adityamds05@gmail.com)**.

Please include:
* Description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact.

We will review and address valid security disclosures promptly. Please do not report security vulnerabilities through public GitHub issues.
